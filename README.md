# Proyek Basis Data - Perpustakaan

Repository ini berisi skrip SQL dan laporan praktikum untuk pengelolaan basis data sistem perpustakaan.

## Identitas Proyek

- **Tema:** Perpustakaan
- **Nama Organisasi:** Perpustakaan Parable
- **Lingkup Layanan:** Perpustakaan Parable mengelola layanan peminjaman dan pengembalian koleksi bacaan secara terpadu, mulai dari pendaftaran anggota, penelusuran katalog buku, hingga pencatatan transaksi harian. Layanan ini mencakup perhitungan otomatis denda keterlambatan, perpanjangan masa pinjam, serta pemantauan stok buku yang tersedia agar proses pengelolaan koleksi dan pelayanan kepada pembaca berjalan lebih tertib.
